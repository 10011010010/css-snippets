## 2. 가변 상품(Variable Product) 세팅 순서

```
상품 편집 > 상품 데이터 > "가변 상품" 선택
```

### Step 1: 속성(Attributes) 추가
```
상품 데이터 → 속성(Attributes) 탭
  → "사용자 정의 속성 추가" 클릭
  → 이름: 사이즈
  → 값: 핑키 | 큰핑키 | 퍼지 | 하퍼 | 마소 | 마중 | 마대 | 특대
  → ☑ "옵션(Variations)에 사용" 체크
  → 저장
```

### Step 2: 옵션(Variations) 생성
```
상품 데이터 → 옵션(Variations) 탭
  → "모든 속성에서 옵션 생성" 클릭
  → 각 옵션별로:
     - 정가(Regular price): 소매가 입력
     - 할인가(Sale price): 필요 시 도매가 입력 (또는 역할 기반 가격 플러그인 사용)
     - 재고 관리: 개별 설정
```

### Step 3: 각 Variation 가격 입력 예시
```
[핑키]  정가: 800   할인가: (비워두거나 도매가 플러그인으로 500)
[큰핑키] 정가: 900   할인가: (비워두거나 도매가 플러그인으로 600)
[퍼지]  정가: 1000  할인가: (비워두거나 도매가 플러그인으로 700)
...
```

## 3. 도매가 세팅 (50마리 이상 주문 시)

### 방법 A: 수량 할인 플러그인 사용 (권장)

**플러그인 예시:** WooCommerce Dynamic Pricing / Quantity Breaks

```
WooCommerce → 설정 → Dynamic Pricing
  → 수량 규칙 추가:
     조건: 수량 ≥ 50
     할인 유형: 고정 가격(Fixed Price)
     핑키: 500원, 큰핑키: 600원 ...
```

### 방법 B: 역할 기반 가격 (B2B 고객 전용)

**플러그인 예시:** WooCommerce Wholesale Prices

```
1. 사용자 역할 "도매(Wholesale)" 생성
2. 각 상품 Variation에 도매 가격 필드 추가
3. 도매 회원 로그인 시 자동으로 도매가 표시
```

### 방법 C: 할인 쿠폰

```
WooCommerce → 쿠폰 → 새로 추가
  → 할인 유형: 고정 상품 할인
  → 사용 제한: 최소 수량 50
```

## 4. VAT(부가세) 설정 — 선택적 적용

### 4-1. 세금 기능 활성화

```
WooCommerce → 설정 → 일반
  → ☑ "세금 및 세금 계산 활성화" 체크
  → 저장
```

### 4-2. 세금 옵션 설정

```
WooCommerce → 설정 → 세금(Tax) 탭
```

| 설정 항목 | 옵션 | 설명 |
|----------|------|------|
| **세금 포함 가격 입력** | "아니오, 세금을 제외한 가격을 입력합니다" | 가격에 VAT 미포함으로 입력 |
| | "예, 세금을 포함한 가격을 입력합니다" | 가격에 VAT 포함으로 입력 |
| **상점에서 가격 표시** | "세금 포함" 또는 "세금 제외" | 고객에게 보이는 가격 |
| **장바구니/결제에서 표시** | "세금 포함" 또는 "세금 제외" | 결제 시 가격 표시 방법 |
| **추가 세금 클래스** | 필요 시 추가 | 면세/감면세율 등 |
| **세금 기준 계산** | 배송지 주소 기준 | 대부분 기본값 사용 |

### 4-3. 세율(Tax Rate) 등록

```
WooCommerce → 설정 → 세금 → 표준 세율(Standard Rates)
```

| 국가 코드 | 시/도 | 우편번호 | 도시 | 세율(%) | 세금 이름 | 우선순위 | 복합 | 배송 |
|----------|------|---------|-----|--------|----------|---------|-----|-----|
| KR | * | * | * | 10.0000 | VAT | 1 | ☐ | ☑ |

### 4-4. VAT 선택 적용 시나리오

#### 시나리오 1: 상품별 VAT 적용/미적용
```
상품 편집 → 상품 데이터 → 일반 탭
  → 세금 상태(Tax Status):
     - "과세(Taxable)" → VAT 적용
     - "없음(None)" → VAT 미적용
  → 세금 클래스(Tax Class):
     - "표준(Standard)" → 10%
     - "영세율(Zero Rate)" → 0%
     - "면세(Reduced Rate)" → 커스텀 세율
```

#### 시나리오 2: 고객 유형별 VAT 적용
```
B2C(일반 소비자): VAT 포함 가격 표시
B2B(사업자): VAT 별도 표시 → 세금계산서 발행

플러그인: WooCommerce Tax Exempt 또는 역할 기반 면세 설정
  → 도매 역할 사용자: 면세 처리
  → 일반 역할 사용자: 과세 처리
```

#### 시나리오 3: 결제 시 VAT 포함/별도 토글

```php
/* functions.php 또는 커스텀 플러그인 */

// 장바구니에서 VAT 포함/별도 선택 필드 추가
add_action('woocommerce_before_order_notes', function($checkout) {
    woocommerce_form_field('vat_display_option', array(
        'type'    => 'select',
        'label'   => 'VAT(부가세) 표시',
        'options' => array(
            'incl' => 'VAT 포함 (기본)',
            'excl' => 'VAT 별도',
        ),
    ), $checkout->get_value('vat_display_option'));
});
```

## 5. 배송비 설정

```
WooCommerce → 설정 → 배송 → 배송 구역
```

| 조건 | 배송비 |
|-----|-------|
| 기본 배송료 | 10,000원 |
| 45,000원 이상 주문 | 무료배송 |

### 설정 방법
```
배송 구역: 대한민국
  → 배송 방법 1: 정액 배송(Flat Rate)
     - 비용: 10000
  → 배송 방법 2: 무료 배송(Free Shipping)
     - 조건: 최소 주문 금액
     - 최소 금액: 45000
```

### 직배송 지역/일정별 배송 구역 분리 (선택)
```
배송 구역 1: 월요일 직배송 지역 (평택, 안성, 오산, 천안)
배송 구역 2: 수요일 직배송 지역 (인천, 고양, 수원, 안산)
배송 구역 3: 금요일 직배송 지역 (서울, 성남, 광주, 의정부)
```
